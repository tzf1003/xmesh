02

让 Agent 帮你安装

把这段提示词交给本机 Agent。它将使用当前版本的说明，先检查环境，再展示安装与配置计划。

03

三步连接

  1. 选择用途和目录

    本机使用、多设备互联或云端 Agent；选定实际工作目录。

  2. 确认权限与客户端

    开发或只读访问，选择 Codex、Claude Code，确认计划后执行。

  3. 登录并验证连接

    需要时在浏览器完成登录，再从客户端发起一次真实请求。

查看计划、恢复与验证命令 ↗
04

遇到问题

安装会报告阶段和下一步操作。保留已校验的安装包，重试同一版本；已开始的配置可使用 job ID 恢复。
