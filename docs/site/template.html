让 Agent 用上你真实的开发机器

xmesh 把设备上的终端、文件和本机已有的 MCP 工具组成网格，通过标准 Remote MCP 交给 Codex、Claude Code 以及云端 Agent。每台机器运行同一个进程，局域网与 Tailnet 自动互联，需要时一键开放带 OAuth 2.1 的公网入口。

它能做什么

⌘

终端与命令

exec.* 执行命令，pty.* 提供可交互的伪终端会话。

⇅

文件读写与互传

fs.* 读写文件，分块上传下载并校验 SHA-256。

◎

本机 MCP 聚合

挂载设备上已有的 MCP 服务，统一以 设备名/工具 暴露。

⌗

多设备网格

LAN 与 Tailnet 共存，首选局域网，断线自动恢复。

☁

云端入口

任一节点可开启 Ingress，提供带 OAuth 2.1 的公网 MCP 端点。

⛨

权限边界

按目录 allow / deny，开发与只读两档权限，并发有租约规则。

2或者，让 Agent 帮你安装

安装提示词

把这段提示词交给本机的 Codex 或 Claude Code。它会按当前版本的说明先检查环境，再展示安装与配置计划，等你确认后执行。

3三步连接

  1. 01

    选择用途和目录

    本机使用、多设备互联或云端 Agent；选定实际工作目录。

  2. 02

    确认权限与客户端

    开发或只读访问，选择 Codex、Claude Code，确认计划后执行。

  3. 03

    登录并验证连接

    需要时在浏览器完成登录，再从客户端发起一次真实请求。

查看计划、恢复与验证命令 →
