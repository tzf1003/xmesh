## 性能

同机、同浏览器、预热后 20 轮，每轮 30 次填写操作。原始数据见 [基准记录](ui-mcp-benchmark-20261019.json)。

| 模式 | 中位数 | P95 |
| --- | ---: | ---: |
| 直接 Playwright | 27.1 ms | 28.8 ms |
| 逐步 MCP | 615.0 ms | 1,144.1 ms |
| 批量 MCP | 73.3 ms | 78.9 ms |

本机批量执行满足 `直接执行 P95 × 1.25 + 250 ms` 的门限。工具调用与字节数统计包含每组一次预热。该基准采用本机 stdio，分布式联调使用回环 HTTP；实际部署的 tailnet、DERP 延迟与业务环境负载需要在相应节点复测。

## 平台验收

`UI test MCP` 工作流执行 Windows、macOS、Linux 的 Web 与通用 Electron 验证，以及 Windows/macOS 的 xmesh 面板验证。各平台以关联 PR 的实际工作流结果为准；交叉编译只证明编译兼容性。

测试结果区分 `fixtures: real/mock` 和 `coverage`。Electron 支持依赖 inspect 开启且实现后台测试契约的测试构建。脚本模式属于可信节点上的代码执行能力；Worker 和后台窗口管理用于故障隔离与资源回收。
