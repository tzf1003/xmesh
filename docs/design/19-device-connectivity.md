# 设备身份与 LAN / Tailnet 共存

## 行为约定

设备以持久公钥生成的 `device_id` 识别。同一设备在目录和界面中显示一条记录，
LAN 与 Tailnet 是它的连接路径。首次连接及断线恢复按 LAN、Tailnet 的顺序尝试；
已经建立的健康连接保持当前路径。

设备在任一路径完成一次 xmesh 配对后，两条路径使用同一份设备信任。
设备的应用角色由 xmesh 本地信任记录授予；网络控制面决定其网络路径是否可达。
撤销 xmesh 信任终止该设备的全部路径与会话。

升级使用配置及设备协议版本 2，结束旧版连接并重新配对。
升级前保存旧配置和信任文件；回滚使用原程序及原配置。旧 Tailnet 配置若仅声明 `tag:device` 的应用授权，迁移将该授权的原有工具与后端限制复制为版本 2 本机使用的 `tag:peer`；已经声明的 `tag:peer` 保持原样。

## 身份与配对

- 状态保存到 `identity-v2`。Ed25519 私钥、证书在一个原子记录中保存，权限为 0600。
- `device_id` 是 `dev-` 加完整的 SHA-256(SPKI) 十六进制摘要。
- 证书续期保留公钥，证书主体绑定设备 ID；显示名称、网络地址单独保存。
- 两种网络都使用 TLS 1.3/mTLS，验证相同的设备公钥和当前信任记录。
- 一次密码配对使用 SPAKE2，将双方版本 2 身份文档纳入确认 transcript。
- 配对引导使用独立 ALPN `xmesh-pair/2`，只能访问 `/mesh/v2/pair/`。
- 密码和信任分别维护版本；确认与版本检查在同一事务中完成，撤销后的旧确认失效。
- 同一设备的名称变化保留本地 alias；同名不同身份分配独立 alias。
- API、CLI 和运行时共用信任服务；离线写入取得文件锁、重新读取、原子替换。

## 网络与目录

配置版本 2 使用 `mesh.lan.enabled` 与 `mesh.tailnet.enabled` 两个开关。
默认开启 LAN，Tailnet 由用户启用。网络组件独立启动、重试与关闭。
某一路未就绪时，其余路径和本机管理仍可运行。

目录以设备 ID 为主键。mDNS、Tailnet 状态和手动地址仅提供候选；
候选经握手证明身份后才归入设备。手动配对地址作为设备的连接提示持久保存，重启或网络组件换代后重新探测；地址复用仍须核验原设备公钥。每条路径独立保存来源版本、验证时间、
健康状态和退避状态。单路发现过期只更新该路径。

每对设备使用一条活动链路；较小设备 ID 的一端负责激活仲裁。
任一端可发起候选连接，只有完成 COMMIT 确认的链路才承载业务消息。
双方进程身份、链路代次和连接 ID 用于拒绝旧连接的迟到结果。

首次连接与恢复的 LAN 候选总预算为 2 秒，包含等待 LAN 发现；收到 Tailnet 连接候选时也给 LAN 相同的优先机会。Tailnet 拨号预算为 5 秒。
失败路径分别按 1、2、4、8、16、30 秒退避。活动链路每 5 秒发送心跳，
响应限时 2 秒。已有连接保持路径，恢复后也不触发额外回切。

同一设备公钥若对应多个经认证的运行实例，目录标记身份冲突，拒绝新连接并结束已有逻辑会话，等待实例冲突消除后建立新会话。

目录向每个订阅者广播最新版本。异步任务提交结果前检查设备身份、网络组件版本、
连接代次和信任版本。配置与 drain/resume 按单调版本顺序应用。

## 逻辑会话

内部节点通信使用 `/mesh/v2/link`，子协议为 `xmesh-link-v2`。
同一设备链路承载多个隔离的 MCP 逻辑会话，恢复时保留 MCP 实例。
调用方身份为 `device_id/logical_session_id`，路径变化保持资源归属。

双向消息使用会话 ID、顺序号、确认号和链路代次。接收方记录消息并入队后确认，
重复消息不会再次交给 MCP。恢复补发未确认帧，覆盖请求、响应、取消、进度和反向调用。
每会话的恢复凭据只保存在内存中，并绑定双方设备身份、进程身份和 OAuth 客户端。

单帧上限为 16 MiB，每会话缓存上限为 32 MiB，进程总上限为 128 MiB。
缓存满时施加背压，控制消息保留额度。物理路径断线后的恢复窗口为 120 秒。

恢复保留 PTY 的 PID、owner 和 cursor、已接受的 exec 任务及结果、per-caller 后端，
以及仍在 TTL 内的租约。请求超时、显式取消和租约到期继续生效。
用户关闭、撤销设备信任、恢复窗口到期或服务退出时执行一次完整清理。正常退出先在 500 毫秒的总预算内通知对端结束逻辑会话，再关闭网络组件；网络中断保留恢复窗口。恢复期限独立于在途拨号，到期后的握手结果不能复活旧会话。
远端进程身份变化结束旧会话；结果不确定的写入或执行不会自动作为新操作再次执行。

## 并发约束与回归

| 交错事件 | 处理规则 | 回归位置 |
| --- | --- | --- |
| LAN / Tailnet 同时发现、同一地址换设备 | 按已验证公钥合并；探测任务包含设备 ID；连接提示不授予信任 | `device/directory_test.go`、`connectivity/node_test.go`、`device/hints_test.go` |
| Tailnet 先出现、LAN 稍晚发现 | 首次拨号和入站仲裁共享 LAN 的有限发现机会 | `devicelink/manager_test.go` |
| 双向同时拨号、多逻辑会话一起重连 | 较小设备 ID 仲裁；COMMIT 与确认完成后唯一激活；旧 epoch 不承载消息 | `devicelink/manager_test.go` |
| provider 关闭、失败重试、旧握手或旧发现迟到 | 关闭时立即撤销旧 provider 代次，提交时再次校验；其余网络独立运行 | `connectivity/node_test.go`、`device/directory_test.go` |
| 配对确认与密码轮换、设备撤销交错 | 同一事务内验证密码版本与设备信任版本；确认回执绑定当前信任 | `device/pairing_concurrency_test.go` |
| 同一公钥对应多个进程 | 发现、拨号、激活与业务接收均检查冲突；结束原会话 | `device/directory_test.go`、`devicelink/manager_test.go` |
| 探测失败与较新成功交错、旧进程地址失效 | 失败按探测开始时间撤销路径证据；迟到失败与旧探测结果不能覆盖较新成功，已失效旧实例证据退出身份冲突判断 | `device/directory_test.go`、`connectivity/node.go` |
| 旧拨号失败、旧 sys.info 回读覆盖新连接 | 仅当前设备与连接代次能发布结果；路径退避分别保存 | `role/gateway/coexist_race_test.go` |
| 断线路径恢复、ACK 丢失、业务重发 | 双向序列与确认去重，恢复已有 MCP 会话；健康路径保持 | `devicelink/session_test.go`、`devicelink/manager_test.go` |
| 恢复期限到达时仍有拨号在途 | 独立执行期限清理，拒绝迟到的激活结果 | `devicelink/manager_test.go` |
| drain/resume、热配置与停机交错 | 管理动作按代次串行；停机等待工作协程退出；资源归属保持设备逻辑会话 | `app/control_test.go`、`connectivity/resources_test.go` |

连接、恢复、离线、设备信任撤销与身份冲突写入 `device_link_*` 审计事件。记录包含设备 ID 和路径类型，可与逻辑会话的工具审计关联。

## 运行期生命周期与应用结果

Funnel 入口和 Tailnet Gateway 监听器使用持续的接收队列，等待路径就绪，并在提供者重建后重新绑定。Funnel 后台启用失败会进入节点警告和配置应用结果，并在监听成功后清除。网络配置重载等待当前路径配置就绪；无法启动的 LAN/Tailnet 路径分别通过 `apply_errors` 的 `mesh.lan`、`mesh.tailnet` 返回，仍在初始化的路径也会在等待截止后返回待应用状态。

入口对同进程 Agent 的调用使用 `tag:ingress` 授权，沿用 OAuth 调用方身份。设备证书在运行期间每小时检查，到期前 30 天使用同一公钥续期；已创建的服务端和客户端 TLS 配置在每次握手时读取当前证书。

逻辑会话在断网期间关闭后保留其已认证的关闭通知，直到对端确认或恢复窗口到期。关闭通知会触发重连并跨承载连接重放，使对端 MCP 会话和调用方资源随之释放。
