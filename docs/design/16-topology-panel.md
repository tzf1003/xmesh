# 拓扑面板

桌面面板以当前内核为观察点展示设备连接、最近调用与运行配置。左侧按网络、安全与接入、运行分组；配置、Tailnet 管理、关于与更新收在「高级」中。顶部搜索支持 Ctrl/Cmd+K，匹配设备或功能，设备结果定位到拓扑详情区。

## 数据与连线

设备来自控制通道的 `peers`，本机身份、角色及运行资源来自 `status`。实线表示 `direct`；虚线经过按区域汇合的 DERP 节点；离线使用淡色点线；在线但连接方式未知时显示「连接方式待探测」。`PeerInfo.error` 单独标记设备信息读取失败。最近调用方来自当前面板保留的调用事件，标签为「最近调用方」。调用方到本机的箭头表示调用方向。

连线描述当前节点观察到的关系。详情区按设备显示地址、版本、最后在线、最近调用和可用管理入口。设备信息使用状态来源提供的字段；远端管理入口打开 Tailnet 管理，本机配置入口打开本机表单。

## 配置与操作

配置关系视图展示运行中的节点角色、Gateway、入口、工作目录与 MCP 后端。点击分支进入对应设置。配置页默认表单，YAML 源码为另一标签；切换前若存在草稿，用户可保留编辑或放弃。两种编辑方式使用现有 dry-run、ETag、权限放宽确认和应用状态提示。

常用操作为接入设备、查看会话、管理授权和配置。排空、强制终止、Gateway 地址与令牌管理、打开日志等集中在首页「运行控制与接入配置」折叠区；危险操作沿用确认流程。接入按钮根据网络模式进入局域网配对或 Tailnet 入网。

## 布局与可访问性

设备槽位按稳定 ID 分配，按本地实例保存在面板会话中；切换页面以及状态、顺序、过滤变化均保持位置。超过八个对端时始终提供完整设备列表入口。多于四个中继区域时使用列表，窄窗口也使用包含近期调用方的列表与纵向详情区。图形中的设备使用可聚焦按钮，详情区标签、搜索和折叠导航可通过键盘操作。浅色与深色跟随系统，字体和缩放沿用显示设置；动效遵循减少动态效果偏好。

## 验收

单元测试验证槽位稳定性、连接语义、本机身份与最近调用方的来源。Electron 端到端测试验证路由、过滤、详情选择、调用更新、配置视图、搜索、草稿切换保护、窄窗口及空状态。原有 Gateway、配对、授权、配置并发写入、审计、CI 运行器与窗口安全测试继续覆盖对应操作。
