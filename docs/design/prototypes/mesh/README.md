# Tailscale 管理 · 设计预览

侧栏独立入口为「Tailscale 管理」。页面以控制面连接摘要开场，分为「设备与标签」「访问策略」「权限矩阵」「DERP 中继」，「接入设备」和管理凭据使用侧边面板。

设备清单支持搜索与状态筛选，详情展示地址、角色、授权和标签。标签修改先检查格式及已应用策略的属主，再预览整组替换。

访问策略、模板与 DERP 编辑共用一份草稿。应用前展示变更行摘要及完整策略；确认时核对预览版本和草稿内容，保存应用前快照。快照恢复到草稿后需再次预览与应用。中继编辑保留已有 region 的其他字段和其余节点。

权限矩阵并列显示网络层与工具层的放行、拒绝和未知，支持只看不一致。DERP 包含示例探测与准入同步流程。设备接入保留标签、有效期、临时节点和密钥文件位置。

顶部提供示例、只读和未连接场景，以及三种配色。只读状态中查看操作可用，写入操作受限。

## 预览与数据边界

所有设备、IP、控制面、版本、延迟与凭据均为示例。页面不发起外部 API 请求，不写入 key 文件，也不验证真实密钥。矩阵为预置示例，不以这些结果推断真实授权。注册、探测、准入同步及控制面写入在页面内模拟。

编辑器的示例检查使用标准 JSON 子集。正式实现应复用现有完整 HuJSON 编辑、策略语义校验、并发冲突保护、快照和失败恢复；按 Tailscale / Headscale 与实际 capability 区分远程写入或服务器文件模式。编辑源存在错误时应先修正，再进行结构化 DERP 编辑。
