# 设备管理 · 设计预览

打开 `index.html` 查看交互方案。预览使用同目录的 CSS 与 JavaScript，可直接在本机浏览器中打开。

## 信息结构

- 本机信息独立呈现，显示设备名称、系统版本、在线状态和连接密码状态。
- 已配对设备为页面主区域，支持全部、在线、离线筛选与搜索。
- 发现设备、手动连接和配对文档集中在右侧。
- 点击设备行查看详情；密码管理、地址配对和配对文档使用侧边面板。
- 本机连接密码采用单次输入，输入框右侧的小眼睛可显示或隐藏当前输入内容。
- 设备详情展示当前路径、备用路径、连接方式、地址、授权标签与最近在线时间。
- 撤销配对与清除密码保留确认步骤。
- 「运行」采用可折叠菜单，CI、Tailscale 与设置有独立入口；顶部角色菜单提供启停和相关设置。执行历史与审计通过「会话」访问。

## 预览内容

顶部可切换「单设备示例」与「多设备示例」，并选择翡翠深色、石墨深色或清透浅色。

单设备场景展示本机在线、连接密码已设置、尚未添加其他设备。多设备场景展示直连、中继、离线及发现设备的界面；示例设备、地址和指纹用于设计预览。

交互在页面内模拟。正式接入时需要读取实时设备能力、网络模式和连接状态，执行现有接口的校验及错误处理。
