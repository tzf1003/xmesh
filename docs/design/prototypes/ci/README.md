# CI 运行器 · 设计预览

侧栏独立入口为「CI 运行器」，页面包含「仓库与实例」「GitHub 账号」「运行环境」。延续设备、会话预览的配色、系统字体、线性图标与侧边面板。

仓库卡片显示实例状态、当前任务、最近结果、绑定来源、并发数和标签。需要处理的实例有明确的修复入口。添加仓库支持账号选仓库、注册令牌、接管已有运行器三条路径；暂停、重启、解绑与公开仓库绑定提供影响说明和确认。

交互包含搜索与状态筛选、实例详情、暂停与恢复、并发标签编辑、重新注册、账号管理及工作流片段复制。顶部可切换示例与空状态以及三种配色。

所有仓库、凭据状态、任务和运行环境均为示例。页面仅修改内存数据，刷新后恢复初始状态；不会注册真实 GitHub 运行器，也不会保存或验证实际凭据。目录检查、任务等待、注册及安装过程在预览中模拟完成。正式接入时沿用仓库的实际能力、错误和状态机，并保留运行任务的排空处理。

## 实现依据

- `ui/src/renderer/pages/Ci.tsx`
- `ui/src/renderer/pages/ci/Binding.tsx`
- `ui/src/renderer/pages/ci/Accounts.tsx`
- `docs/contracts/schemas/control-ci.schema.json`

当前契约提供每个实例的当前任务与最近一次结果，设计据此展示。完整任务历史、任务日志、账号实时校验和环境诊断需要对应数据源支持。并发变更需保持实际运行实例的生命周期，示例页的立即更新不代表后台行为。
