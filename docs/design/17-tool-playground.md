# 工具调试台

面板在「运行 → 工具调试台」选择本机、远端设备或 Gateway，浏览工具并填写参数。工具名称和 JSON Schema 来自当前 Gateway；远端工具通过 `tools.search` 查询，包含未默认展开的 MCP 后端。搜索词由服务端继续过滤，达到 100 条时显示截断提示。刷新工具保留当前参数。

## 调用路径

渲染进程通过固定的 `playground` IPC 发送经过大小和类型校验的请求。主进程使用 MCP SDK 连接所选内核报告的本机回环 `/mcp`，读取与连接命令相同的现有 PAT。URL、HTTP 方法、Authorization 和来源标志由主进程确定。SDK 负责初始化、协议协商、SSE、取消和工具变化通知；SDK 在构建时打包到主进程产物。

工具调用携带 `X-Xmesh-Origin: panel`。Gateway 在会话初始化时记录声明，调用审计增加可选 `origin: "panel"`，审计页显示面板标识。此字段仅供展示和关联，权限仍由原有 PAT scopes、目标设备授权、配额和策略决定。未声明来源的客户端无法据此判定为 AI。Agent 的审计保留自己的身份和字段。

连接按实例、内核 boot ID、本机 Gateway 地址及 PAT 绑定。切换实例、内核离线、地址变化或应用退出会关闭旧连接；下次访问读取新凭据，凭据轮换沿用现有操作。工具执行时保留 MCP 连接以支持同一会话的默认值、租约和后续终端操作。

## 参数和结果

基础字段有字符串、数值、布尔值和枚举表单，复杂值使用 JSON 编辑。原始 JSON 保留完整参数；本地进行语法及基础类型、必填和范围检查，完整 JSON Schema 及业务规则由目标工具验证。内置删除与带 destructiveHint 的工具执行前显示目标和工具确认。

响应区区分工具错误、协议错误、连接错误、超时与取消，保留原始 MCP 响应，并提供文本和结构化视图、复制和原生保存对话框。超过 64 KiB 的结果默认折叠。超时和取消均提示远端状态仍需检查。

参数历史只在当前页面会话内保留最近 30 次摘要；env、stdin、data、content、password、secret、token 等字段递归替换为占位符，回填后须重新填写才能执行。通用工具参数上限为 256 KiB，最多 8 个同时运行的调用，每次超时为 1–1800 秒。

## 专用操作界面

后续独立 PR 在同一调用底座上提供 PTY 终端和文件传输。终端使用会话所有权和增量读取；文件传输按目标节点实际发布的 fs.upload/fs.download schema 探测能力，上传下载字节和哈希处理在主进程完成。

## 验证

单元测试使用真实 MCP SDK 测试服务器验证初始化、调用、取消、工具变化和凭据轮换。Go Gateway 测试验证来源审计及权限保持。Electron 测试覆盖表单、JSON、结果、错误、历史脱敏回填与刷新保留参数，相关安全和 Gateway 页面回归一并运行。跨设备生产部署与 Windows/Linux 原生交互仍需对应环境验收。
