# 自定义紧凑托盘面板

xmesh 的系统托盘图标打开独立的 400 × 580 DIP 面板，使用浅灰浮层、圆角卡片、顶部页签与固定底栏。面板由 Preact 渲染，数据和操作复用桌面端现有的控制连接。

## 页面与操作

| 页面 | 内容与操作 |
| --- | --- |
| 概览 | 当前节点、网络模式、在线设备、连接关系、终端与共享执行用量、最近三次调用；复制网关连接信息、暂停 / 恢复新任务 |
| 设备 | 名称 / 操作系统 / 地址搜索、仅在线筛选、连接方式、详情、地址复制和远程终端入口 |
| 服务 | 网关地址、Claude Code / Codex 连接配置、MCP 后端状态；有运行器时展示 CI 摘要 |
| 活动 | 本次连接的最近 100 次调用，保留真实时间、调用方、设备、工具、结果与耗时；支持失败筛选和详情 |
| 托盘设置 | 登录启动、主窗口设置入口、配置 / 日志 / 审计目录、重启 / 停止内核 |
| 固定底栏 | 更多操作、主窗口、退出界面 |

主题跟随系统，字体与缩放继承桌面显示偏好。正文独立滚动，页签和底栏保持可见；工作区不足时限制浮层尺寸。每个实例分别记忆所选页签与各页滚动位置。

暂停对应 drain keep：拒绝新调用，已有任务继续运行。退出界面仅结束桌面进程。停止和重启使用自定义确认，显示节点名称及 PTY / exec / CI 用量，并在执行时重新检查实例和 boot ID。

复制连接信息与客户端配置包含网关的访问凭据。令牌在主进程读取并写入剪贴板，托盘 renderer 接收操作结果。读取凭据期间节点变化时取消复制。

## 窗口生命周期

- macOS / Windows 左键切换自定义浮层，右键进入浮层的更多操作区。
- 点击浮层之外导致失焦时隐藏；Esc 按弹窗、下拉、设置页、浮层的层级关闭。
- 首次点击创建一个隐藏且受沙箱保护的窗口，加载完成后显示。后续显示复用窗口。
- 隐藏期间停止向该 renderer 推送状态；再次打开推送完整最新快照。内核连接继续为图标和主窗口服务。
- 位置按托盘图标所在显示器的 workArea 计算，候选位置为下 / 上 / 右 / 左，结果限制在工作区内。坐标统一为 DIP，支持负坐标与多屏。
- 图标位置不可用时使用鼠标所在显示器。显示器移除或显示参数变化时重新定位。
- macOS 对托盘点击引发的 blur / click 顺序去抖。Windows 合并连续激活，避免双击导致闪烁。
- 加载失败提供原生菜单恢复入口；renderer 退出后下一次激活重建，连续失败进入原生菜单。
- Linux Wayland 采用原生菜单兼容路径；其他 Linux 桌面依赖其托盘激活能力。`XMESH_TRAY_UI=native` 可强制原生路径。

## 数据与状态

同一选中实例继续使用一个 ShellController、一个控制客户端和一条 SSE。托盘从明确字段选择器生成 DTO：节点、网络、设备、用量、后端、网关地址、警告、可用动作和近期调用。

活动记录保留事件 ID、事件时间、实例和 boot ID，按事件 ID 去重，最多 100 条。切换实例及内核启动代次变化时清空旧记录。原有最近调用 API 继续提供原始 CallEventData，以维持主窗口兼容。

状态优先级沿用 deriveIcon：离线、协议不兼容、排空、待重启、降级、健康。无配置时进入设置向导；已配置停止、未响应与残留状态展示对应恢复动作。系统服务残留状态提示管理员处理。缺少路径或能力时禁用相应按钮。

`revision` 为托盘状态修订号，renderer 忽略更旧的响应。主进程推送以 100 ms 合并突发变更；手动刷新复用现有控制连接。

## 受限通信与维护确认

托盘使用 `app://tray/index.html` 和专用 preload。只有登记的托盘 WebContents 顶层页面、精确入口 URL 能调用三个固定 IPC 频道：读取状态、执行受限命令、隐藏浮层。主窗口原有 IPC 仍只认可主窗口。

托盘命令校验字段形状、字符串长度、目标实例与 boot ID。动作 ID 由主进程根据最新菜单模型解析，可用性与原生菜单保持一致。终端与配置写入等复杂操作在主窗口继续执行。

停止 / 重启分两步：主进程签发一次性确认令牌，renderer 显示影响；确认后主进程校验有效期、目标代次和动作可用性。令牌使用后销毁，隐藏浮层时取消待确认。执行使用共用 Actions，确认只出现一次。

安全窗口设置与主窗口一致：contextIsolation、sandbox、关闭 Node 集成，固定本地资源与严格 CSP，renderer 无网络连接权限。配置、工作目录、环境变量和工具参数 / 输出不进入托盘 DTO。

## 主窗口导航

托盘只提交白名单页面和当前设备标识。主进程验证设备属于当前快照，排队保存最新导航目标，等待准确的主窗口 renderer 订阅就绪后投递。

主窗口接收目标后定位到设备或终端。页面有未保存编辑时显示放弃确认；取消保留当前编辑。主窗口上报 dirty 状态时，托盘实例切换先引导用户处理该编辑。

## 源码分工

| 位置 | 职责 |
| --- | --- |
| `ui/src/shared/tray.ts` | DTO、命令与参数校验、窗口导航目标 |
| `ui/src/main/tray.ts` | 系统托盘图标、点击事件和原生兼容菜单 |
| `ui/src/main/tray-window.ts` | 自定义浮层创建、显示 / 隐藏、定位与故障恢复 |
| `ui/src/main/tray-position.ts` | 紧凑尺寸和工作区定位纯函数 |
| `ui/src/main/tray-service.ts` | 展示投影、修订号、可用动作与一次性确认 |
| `ui/src/main/tray-ipc.ts` | 托盘发送方身份与固定频道 |
| `ui/src/main/panel-navigation.ts` | 主窗口导航排队与订阅握手 |
| `ui/src/preload/tray.ts` | 专用冻结 API |
| `ui/src/renderer/tray/` | Preact 界面、交互与主题样式 |

构建脚本在现有 `dist/renderer` 下增加 `tray/`，主窗口与托盘分别打包。现有安装包文件规则包含两份 renderer 资源，不增加生产依赖。

## 验证

单元测试覆盖工作区边界、命令校验、窗口身份、字段投影、陈旧目标、单次确认、权限变化、dirty 编辑保护、导航握手和活动启动代次。原生 Electron 测试覆盖四页、复制、设备搜索、活动详情、暂停恢复、维护确认、隐藏后同步、主窗口导航及异常状态。

macOS 本地自动化使用隔离的假内核与用户目录。Windows / macOS 的 CI 继续运行完整 UI 测试。真实系统托盘位置、自动隐藏任务栏、混合 DPI、全屏空间和安装包行为需要对应物理系统验收；浏览器或隐藏窗口测试不替代这些系统集成检查。
